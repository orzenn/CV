## 2. Три вопроса

**2.1. На каких кадрах выигрывает путь контуров, на каких — Хаф + RANSAC, и почему? Что общего у кадров, где проигрывают оба?**
Путь контуров стабильно выигрывает на кадрах с хорошим освещением и чистым фоном (например, кадры 03 и 07), где граница листа не прерывается и образует идеально замкнутый прямоугольник. Путь Хаф + RANSAC лучше справляется с кадрами 14 и 15: на 15-м кадре угол листа перекрыт посторонним предметом, из-за чего контур рвется, но RANSAC успешно достраивает прямые из разрозненных обрывков краев. Оба пути полностью проиграли на 10-м кадре (IoU = 0.0). Общее у таких отказов — слишком низкий контраст листа с темным столом или глубокая тень, из-за чего алгоритм Canny не находит перепада яркости, и на карте краев нет даже обрывков границ.

**2.2. Правило медианы для порогов Canny: на скольких кадрах из пятнадцати сработало, где и почему ошиблось, что показала фиксированная пара? Что вы оставили в своём сканере?**
Правило медианы сработало на 10 кадрах из 15 (средний IoU 0.758). Оно ошибается на темных кадрах (например, кадр 06, где медиана яркости всего 38). При этом пороги падают до 25/51, из-за чего детектор захватывает слишком много фонового текстурного шума, мешающего поиску. Фиксированная пара `--canny 50,150` показала себя лучше: с ней было найдено 11 кадров из 15 (IoU вырос до 0.876). Граница белой бумаги обычно дает сильный градиент (выше 150), а мелкий шум надежно отсекается нижним порогом. В итоговом сканере оставлена фиксированная настройка `--canny 50,150`.

**2.3. Шум и текст: какая σ шума у ваших кадров при разном свете, какую σ фильтра выбрала программа, сошёлся ли остаток с формулой? Что меняет закрытие текста — в числах?**
Уровень шума составил 0.99 (день), 0.74 (лампа) и 0.25 (полумрак). Программа корректно подбирала σ фильтра: при добавленном шуме 10 σ составила 2.86, а измеренный остаток шума (1.0) практически идеально сошелся с предсказанием по формуле (0.99). Отключение морфологического закрытия (`--close 0`) оставляет текст на листе, превращая его в ложные границы: на кадре 06 доля краев выросла с 0.78% до 1.3%, а число отрезков Хафа подскочило с 23 до 40. Из-за этого мусора путь `hough` по всему набору стал находить лишь 4 листа вместо 6.

## 3. Негативные кадры и отказы

На всех трех негативных кадрах (16, 17, 18) программа корректно ответила «не найдено» (IoU = null во всех режимах). Это произошло благодаря проверкам геометрии и функции `looks_like_paper`: найденные прямоугольные объекты не прошли проверку на то, что их внутренняя часть светлее внешнего кольца (правило альбедо бумаги). 

Единственный полный отказ на кадре с листом произошел на снимке 10 (IoU 0.0 для обоих методов). Причина: из-за низкого контраста границы листа слились с фоном, и алгоритм Canny не смог выделить непрерывные перепады яркости. Чтобы это исправить, помогла бы локальная адаптивная бинаризация перед выделением границ или использование нейросетевого сегментатора вместо классического детектора Canny.

## 5. Команды

Всё, что лежит в `out/`, получено этими командами (скопируйте из консоли):

```bash
python docscan.py noise data/01.jpg --add-sigma 5
python docscan.py edges data/09.jpg -o out/09_edges.png
python docscan.py edges data/09.jpg --close 0 -o out/09_edges_noclose.png
python docscan.py edges data/09.jpg --canny 50,150 -o out/09_edges_canny.png
python docscan.py edges data/06.jpg -o out/06_edges.png
python docscan.py edges data/06.jpg --close 0 -o out/06_edges_noclose.png
python docscan.py eval data --ann data/corners.json --seeds 20 --csv out/eval.csv --overlays out/eval
python docscan.py eval data --ann data/corners.json --canny 50,150
python docscan.py eval data --ann data/corners.json --close 0
python docscan.py binarize data/text-lamp.png --method all --gt data/text-gt.png
python docscan.py binarize data/11.jpg --method all -o out/11_bin.png
python docscan.py scan data/12.jpg -o out/12_scan.jpg --bw out/12_bw.png
python docscan.py scan data/15.jpg -o out/15_scan.jpg --bw out/15_bw.png
python docscan.py video --source 0 --method contour --seconds 10
python docscan.py video --source 0 --method hough --seconds 10
python docscan.py video --source 0 --method auto --seconds 10 --save out/video_auto.mp4
```
